# Exemplo de referência

Arquivos em `references/` são material de apoio para a Skill. Nesta fase o
Enslaved apenas **detecta e lista** esses arquivos; nada é executado.

Uma Skill futura poderá pedir permissão explícita para ler ou executar algo,
e cada ação será registrada no log de auditoria (contratos em `backend/tools/`).
